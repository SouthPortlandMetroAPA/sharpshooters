SharpShooters API

v2

Read-only, public league-leaderboard data for the South Portland Metro APA. No key or sign-up. CORS-open, JSON everywhere. Built so ChatGPT or any tool can poll the latest results.

Requests are keyed by season + year — e.g. ?season=summer&year=2026. Omit both to get the current session automatically. Live data is served from https://sharpshooters.spmapa.workers.dev; this page documents it.
Machine-readable spec (import into a ChatGPT custom GPT / Action): /openapi.json.

Recommended polling flow

1. /latest → read season + year 2. /divisions?season=&year= → pick a division_number 3. /sp?division=&season=&year= → the leaders

Endpoints

GET/latest

The current session — { season, year, session_id, name, is_current }.

  • /latest
GET/sessions

Every session that has data, newest first. area=spm · cr · both

  • /sessions
  • /sessions?area=both
GET/divisions

Divisions for a season + year (defaults to the latest session). Each: division_number, name, format, night_of_play, num_teams. seasonyeararea

  • /divisions
  • /divisions?season=summer&year=2026
  • /divisions?season=spring&year=2026&area=both
GET/sp

SharpShooter (SP) leaders for a division + season + year. Omit division for League Leaders across the whole area. seasonyeardivisionarea

  • /sp?season=summer&year=2026 — League Leaders
  • /sp?division=013&season=summer&year=2026
  • /sp?season=spring&year=2026&area=both
GET/leaders

Back-compatible alias of /sp. Also accepts session_id and divisions= (comma-separated). Existing callers keep working unchanged.

  • /leaders
  • /leaders?session_id=2
  • /leaders?divisions=013,015

Response shape — /sp & /leaders

{
  "scope":        "Divisions" | "League Leaders",
  "session":      { "id", "name", "season", "year", "is_current" },
  "divisions":    ["013", ...] | null,
  "operator_ids": [1],
  "report_ids":   [54],
  "generated_at": "2026-07-24T02:17:26Z",
  "leaders": [
    {
      "code":       "r",
      "label":      "8-Ball Rackless",
      "top_count":  7,
      "leaders":  [ { "name": "First \"Nick\" Last", "count": 7, "member_number": "24415" } ]
    }
    // one entry per SP category
  ]
}

Areas

area=spm (South Portland Metro, the default) · area=cr (Columbia River) · area=both. Or pass raw operator IDs: operators=1,2.

Source of truth: the same computation the SharpShooters leaderboard renders — verified equal for every division in every session.
